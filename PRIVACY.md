# CleanWeb Privacy Policy

Effective date: April 24, 2026

CleanWeb does not collect, sell, share, or transmit personal data.

## What CleanWeb Stores

CleanWeb stores extension preferences locally in your browser, including:

1. Filter settings such as blur, grayscale, darkening, and media type controls.
2. The temporary pause timer state.
3. Sites you choose to allow or protect.
4. The popup theme preference.

This information is stored using Chrome extension storage and is used only to make the extension work as configured.

## Website Access

CleanWeb needs access to web pages so it can apply your selected filtering settings to page content such as images, videos, iframes, and background media.

CleanWeb does not read, collect, or transmit browsing history or page content to any server.

## Remote Servers

CleanWeb does not use remote servers for analytics, tracking, advertising, or data processing.

## Data Sharing

CleanWeb does not share user data with third parties.
