Tahir
Release Notes / v2.0.0
Redesigned
What Changed

Tahir is no longer just a blur toggle.

This release rebuilds Tahir around a more complete browsing control flow. Instead of simply blurring media and getting out of the way, it now lets you decide what gets softened, what gets dimmed, what gets hidden, when protection should pause, and which sites should stay untouched.

The popup was redesigned as a compact control panel, and this page has been rewritten to reflect what the extension actually does today.

Current Scope

What Tahir does now

Media Filtering

Tahir can apply protection to regular images, videos, iframes, and inline background images across the page.

Visual Control

You can enable or disable blur itself, change blur intensity, turn grayscale on, and add darkening for a stronger shield.

Video Removal

Tahir can go beyond blur and fully remove videos plus common embed players from the layout when you want a stricter mode.

Session Control

You can pause protection for 5 minutes and let it auto-resume.

Selective Access

With the keyboard shortcut, you can temporarily unblur or reblur the item under your cursor without changing everything else.

Per-Site Rules

The current domain can be added to a whitelist so trusted sites stay clean while Tahir continues working everywhere else.

Release Highlights
  • A new popup interface: a cleaner, faster control surface with the same settings organized into a more usable flow.
  • More precise filtering: Tahir now treats blur, grayscale, darkening, and video hiding as separate controls instead of one rough behavior.
  • Better real-world coverage: background images and embedded media are part of the filtering model, not just plain img tags.
  • Faster temporary overrides: pause now has its own flow, countdown state, and automatic resume.
  • Cleaner exceptions: whitelisting is now a current-site action directly inside the popup.
  • A stronger browsing mode: if blur is not enough, video elements and major embeds can be hidden entirely.
Shortcuts
  • Alt+K unblurs or reblurs the item under the cursor.
  • Alt+P pauses Tahir for 5 minutes.
